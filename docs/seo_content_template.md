# SEO Article Template (EN)

## Front-matter (copy into CMS)
- slug:
- primary_keyword:
- secondary_keywords:
- search_intent: informational / commercial / comparison
- meta_title: (50–60 chars)
- meta_description: (150–160 chars)
- canonical_url:
- publish_date:

## Article structure
- H1 (contains primary keyword)
- Intro (2–4 short paragraphs; state problem + promise)
- Table of contents (optional)
- H2/H3 sections
- Examples (at least 3)
- Checklist / TL;DR
- Soft CTA (AdSpector mention)

## SEO best practices checklist
- One clear primary keyword + consistent terminology
- Use descriptive H2s (include variants naturally)
- Short paragraphs; scannable bullets
- Add internal links:
  - /features (and relevant sub-sections)
  - 1–2 feature deep links (Feed Management, Audits, Alerts, AI Advisor)
- Add 1 external authoritative link (Google docs) when relevant
- Image suggestions + alt text (optional)
- FAQ section (2–5 Qs) if topic is broad
